System Overview #

Xencode is an AI-powered coding assistant platform built as a dual-stack architecture — Python feature system + Rust core runtime (12 crates, 65 tests). It provides CLI, TUI, and API interfaces, multi-model AI support (local Ollama + cloud), agentic coding workflows, code analysis, security scanning, collaboration server, plugin management, and project analysis.

Python Stack: Entry Points #

🚀 xencode_core.py

Primary startup. main() at ~1807 lines. Initializes model providers, smart context, code analyzer, system checker, TUI, Ollama fallback, model selector.

🚀 xencode/cli.py

Click-based CLI (2700+ lines). All command groups + register_feature_commands() for dynamic feature registration.

🚀 xencode/tui/

Textual-based TUI with 31 widget panels. Entry at xencode/tui/__main__.py.

🚀 xencode/api/

FastAPI server. Routers: analytics, code analysis, documents, workspace, monitoring, plugins, vault. JWT auth on protected routes.

🚀 xencode/agentic_cli.py

Standalone agentic CLI entry point. Thin wrapper at ~6 lines.

File: xencode/cache/advanced_memory_manager.py

Already has a complete concrete implementation with:

  • RAMTierManager — In-memory LRU cache with priority scoring (CRITICAL/HIGH/NORMAL/LOW/ARCHIVE)

  • PredictiveCacheAdvisor — ML-based access prediction using sklearn LinearRegression
  • AdvancedMemoryManager — Orchestrator with 4 memory tiers, auto-tier balancing, background cleanup/prefetch workers, and singleton factory
