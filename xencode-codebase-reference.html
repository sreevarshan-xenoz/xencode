System Overview #

Xencode is a comprehensive AI-powered coding assistant platform that integrates multiple AI models (Ollama, cloud providers), provides CLI/TUI/API interfaces, supports collaborative coding, code review, project analysis, and features an agentic system for autonomous coding tasks. It has a modular plugin architecture and integrates with Bytebot for container-based desktop agent functionality.

Entry Points #

The system has three main entry points, plus supporting wrappers:

🚀 xencode_core.py

Python Main Entry

Primary entry point with main() function (line 1807). Initializes all systems: multi-model manager, smart context, code analyzer, project context, system checker, intelligent model selector, Ollama fallback, TUI, model providers.

Key functions: main(), run(), lazy imports throughout

🚀 xencode_cli.py

Python CLI Wrapper

Thin CLI wrapper that imports and runs xencode.cli.cli. Has a main() function (line 17).

from xencode.cli import cli
def main():
    cli()
🚀 xencode/tui/

Python TUI App

TUI application built with Textual framework. Entry at xencode/tui/__main__.py (line 13). Main app class in tui/app.py.

Subdirs: widgets/ (31 panels), features/, utils/

🚀 xencode/cli.py

Python CLI System

Main CLI module with Click commands. ~2700+ lines. Contains all CLI command groups and register_feature_commands() for dynamic feature registration.

🚀 xencode/api/

Python API Server

FastAPI-based API server at api/main.py. Includes feature_routes.py for dynamic feature endpoint registration. api/routers/vault.py adds 3 vault endpoints (GET /health, POST /init, POST /migrate) for credential vault management via the API.

🚀 xencode/agentic_cli.py

Python Agentic CLI

Standalone agentic CLI with main() function (line 6). Separate entry for agent-driven workflows.

Many files use function-level lazy imports, which is good for startup time. But some overwrite local variables multiple times (e.g., xencode_core.py re-imports ModelChecker inside different functions). Consider extracting to module-level lazy loading.
